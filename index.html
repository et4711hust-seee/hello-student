02 / KIẾN THỨC CỐT LÕI

Hiểu vai trò trước khi nhớ cú pháp.

HTML

Trang có những gì?

Dùng thẻ để tổ chức nội dung và mô tả ý nghĩa của từng phần.

  • Cấu trúc: html, head, body.
  • Ngữ nghĩa: header, nav, main, section.
  • Nội dung: h1–h6, p, a, img, ul.
  • Biểu mẫu: label, input, button.
<h1>Hello Web</h1>

Mỗi ô nhập cần nhãn. Ảnh cần văn bản thay thế phù hợp.

CSS

Trang trông như thế nào?

Chọn phần tử rồi khai báo thuộc tính và giá trị để định dạng.

  • Selector: tên thẻ, .class, #id.
  • Box model: content, padding, border, margin.
  • Bố cục: Flexbox và Grid.
  • Responsive: media query theo màn hình.
.card { padding: 24px; }

Cascade giải quyết xung đột theo mức ưu tiên, độ đặc hiệu và thứ tự khai báo.

JavaScript

Trang phản hồi ra sao?

Lắng nghe sự kiện, xử lý dữ liệu rồi cập nhật giao diện qua DOM.

  • Dữ liệu: const, let, chuỗi, số.
  • Logic: hàm, if, vòng lặp.
  • DOM: querySelector, textContent.
  • Sự kiện: click, input, change.
count += 1;

DOM là mô hình đối tượng của tài liệu mà JavaScript có thể đọc và thay đổi.

03 / THỬ SỨC TRONG 5 PHÚT

Bạn đã hiểu ba mảnh ghép?

Thử làm, rồi mở gợi ý để tự kiểm tra.

01. Đổi tên và giải thích phần nào đã thay đổi.

Nội dung tiêu đề trong DOM thay đổi. Ô nhập phát sự kiện input; JavaScript dùng textContent để cập nhật. Cấu trúc thẻ HTML vẫn giữ nguyên.

02. Bỏ bo góc và chuyển sang bố cục ngang.

Kéo thanh bo góc về 0; bật Flexbox. CSS thay đổi border-radius và flex-direction, còn nội dung của thẻ không đổi. Trên màn hình hẹp, bố cục tự chuyển thành dọc.

03. Bấm Thích ba lần. Biến đếm bằng bao nhiêu?

Từ giá trị khởi đầu 0, biến likes tăng lên 3. Trình xử lý sự kiện click cập nhật textContent của bộ đếm. Tải lại trang sẽ đưa trạng thái về mặc định.
